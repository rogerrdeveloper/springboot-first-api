# Spring Boot Hello API

Projeto de uma API REST simples criada com Spring Boot para fins de estudo.

## Tecnologias utilizadas
- Java
- Spring Boot
- Maven

## Funcionalidade
- Endpoint GET que retorna uma mensagem simples

## Endpoint

GET /v1/hello

Resposta:
Hello World!

## Como executar

1. Clonar o repositório
2. Abrir em uma IDE (IntelliJ ou VS Code)
3. Executar a classe principal SpringBootEssencialsApplication
4. Acessar no navegador ou Postman:
   http://localhost:8080/v1/hello

## Objetivo do projeto
Projeto criado para aprendizado inicial de APIs REST com Spring Boot.
